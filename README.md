# AI 招聘官

> **帮 HR 省时间，不是帮程序员秀技术。** 传简历 → 等结果 → 点通过/驳回，三步完事。

## HR 3 步走（不写技术名词）

```

第 3 步：点「通过」或「驳回」（结果、理由、证据都摊开给你看）
```

## 为什么不用老办法

- **vs Moka / 北森（ATS）**：它们管流程，我管判断。ATS 还是人逐份看简历、写面评；我自动做。
- **vs 直接贴 ChatGPT**：ChatGPT 是临时工（每份都要复制粘贴、无统一标尺、无存档）；我是流水线（自动规模化、统一标尺、证据可追溯）。
- **vs 不用系统**：HR 处理 1 份简历约 3 分钟（初筛 1.5 + 邀约 0.5 + 面评 1）× 日均 60 份 = 3 小时/天。系统替代初筛与面评后，每天省约 2.5-3 小时。

## 它能做什么（核心能力，不列技术细节）

- **自动筛简历**：规则卡硬门槛（学历/年限/必备技能/薪资上限，不满足直接淘汰并给原因）→ 语义匹配 → 加分项 → 综合排序。**每个分数怎么来的，有评分卡可查。**
- **自动 AI 面试**：按岗位问、追问细节、识别含糊回答，面完自动出报告（能力雷达图 + 证据链引用原话）。
- **自动出结果**：报告推送到钉钉/飞书/企业微信群，HR 在群里/审批流里点「通过/驳回」，系统自动发通知、生成 Offer、安排入职。

## 上手（5 分钟跑起来，需 Python 3.10+）

1. 项目根目录建 `.env`，填 `DEEPSEEK_API_KEY=sk-xxx`
2. `python -m pip install -r requirements.txt`
3. 双击 `start.bat` 或 `python app.py` → 浏览器打开 http://localhost:7860
4. 演示数据：`demo_resumes/` 10 份简历，直接批量导入试跑

可选配置（`.env`）：登录账号密码、钉钉/飞书群机器人 webhook、Webhook API Key、PostgreSQL 连接。

## 技术细节（仅供技术评审参考，HR 不必读）

<details>

**算法（全部可解释，不黑盒）**
- 综合分 = 规则层 60%（硬门槛+满足度）+ 语义匹配层 30%（BM25+TF-IDF 混合检索 + RRF 融合，Embedding 适配位）+ 加分层 10%（大厂/证书/项目复杂度）
- 面试：动态难度状态机（代码正则判定，非 LLM 自评）+ 多考官证据链评审 + 断点续面
- 评分卡：每层得分 + 依据 + AI 证据引用 + 人工复核留痕，保留 365 天

**数据与合规**
- 9 张表：候选人状态机（含审批链：业务审批→薪酬定薪→最终审批，背调在 Offer 接受后）/岗位规则/评分卡/通知/Offer/HR 反馈
- 多租户（tenant_id 隔离，集团可跨租户聚合）、授权日志（auth_source）、PIPL 级联删除（5 表+文件）
- 偏见守护测试：打分与性别/年龄/姓名无关（确定性证明）

**外部集成（无感）**
- Webhook 服务（端口 7861）：简历入库 / HR 决策回调 / 数据删除，X-API-Key 鉴权
- 钉钉/飞书/企业微信群机器人推送；数据源接口（本地文件已实现，BOSS/猎聘适配位）
- ATS 集成约定：Moka 为主数据源，只读入候选人、回写评估结果，不改其状态机

**容错**
- LLM 超时：指数退避重试 3 次，失败留在队列可重试
- 面试中断：状态落盘，断点续面
- 批量 1000 份：异步后台任务 + 进度接口（GET /batch/{id}/progress）+ 完成推群

**测试与部署**
- 168 个单元测试全绿（全部 mock，不调真实 API）+ 3 条 live 冒烟测试（opt-in）
- Dockerfile + docker-compose 一键部署（数据卷持久化）
- SQLite 默认 / PostgreSQL 切换（DB_TYPE=postgres，迁移清单见 docs/04）

**边界（诚实声明）**
- 演示环境"智能匹配"不接招聘平台简历池（平台 API 为适配位，方案见 docs/02）
- AI 模拟候选人未经真人面试验证（M3 语音面试阶段含真实用户测试项）
- 语音层多口音 ASR 偏差为 M3 显式测试项（5 口音 × 30 样本，偏差 >10% 标人工复核）
