# 招聘平台对接技术方案 + 工时/成本表（v1 · 给领导确认）

> 优先级最高。原则：**官方 API 优先；无 API 用 RPA + 企业授权账号模拟人工操作；不碰爬虫（合规红线）**。

## 一、各平台开放能力摸底（需商务沟通确认）

| 平台 | 官方能力 | 对接方式 | 备注 |
|---|---|---|---|
| BOSS 直聘 | 开放平台（需企业认证+付费套餐） | API 拉取简历/职位发布 | 简历字段完整度高，主流首选 |
| 猎聘 | 企业版简历推送接口 | API 推送/拉取 | 中高端岗位资源强 |
| 智联招聘 | 企业版 API | API | 简历量最大，质量参差 |
| 拉勾/前程无忧 | 部分开放 API | API 或 RPA | 二线备选 |

**决策建议**：先接 1 个平台跑通闭环（推荐 BOSS 或猎聘，取决于目标岗位类型），验证效果后再横向扩展。

## 二、对接技术方案

### 方案 A：官方 API（首选）

```
平台API ──▶ 同步适配器（2小时轮询）──▶ 字段映射 ──▶ 候选人入库（授权日志）
   │                                          │
   └── 异常重试（指数退避 1s/2s/4s，3次）     └── 简历文件落盘 + 解析
```

- **拉取频率**：每 2 小时增量同步（新投递/新匹配）；简历详情按需拉取
- **字段映射**：平台字段 → 系统标准字段（姓名/学历/年限/技能/期望薪资/求职状态/附件），映射表可配置
- **异常处理**：token 过期自动刷新；限流退避重试；失败简历进重试队列 + 告警
- **授权合规**：平台投递行为本身含候选人授权（平台条款），入库时记录 `auth_source=平台接口·授权`，保留平台侧授权凭证快照

### 方案 B：RPA + 企业授权账号（无 API 场景兜底）

- 工具：影刀/来也 UiBot（或 Python + Playwright 自研）
- 原则：使用**企业自己的授权账号**模拟人工操作（查看/下载企业收到的简历），不绕过登录、不爬公开数据
- 节奏：每次会话限速（模拟人工节奏，3-5 秒/页），工作时段执行
- 合规：账号操作留日志（截图/步骤记录），候选人数据来源仍为"平台投递"（授权链完整）

### 方案 C（当前演示）：本地授权上传 + 文件夹导入

已上线：候选人主动提供简历（本地上传/文件导入），`auth_source=候选人授权·本地上传` 记录授权日志。作为 MVP 期间的数据来源，也是合规双路径之一（用户授权 + 平台接口）。

## 三、工时/成本预估

| 项目 | 工作量 | 成本 | 说明 |
|---|---|---|---|
| 方案 A：平台 API 对接（1 平台） | 1.5-2 人周 | 平台年费 5k-3w/年（企业版） | 含字段映射/重试/监控 |
| 方案 B：RPA 适配器 | 2-3 人周 | RPA 工具许可 ~1w/年 | 含人工节奏控制与日志 |
| 方案 C：本地授权上传（已上线） | 0 | 0 | 兜底路径 |
| 通知通道：企业微信机器人 | 3 人日 | 免费 | 推荐首选 |
| 通知通道：短信 | 2 人日 | ~0.05 元/条 | 按量付费 |
| 合计（A + 企业微信） | **约 2 人周** | **5k-3w/年** | 2 周内可跑通 MVP 闭环 |
