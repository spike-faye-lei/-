从零开始，把智能厨房系统跑起来。

## 二、后端部署（电脑端）

### 1. 环境要求

- Python 3.10+
- 训练好的模型文件（见下文"模型文件"）

### 2. 安装依赖

```bash
cd SmartKitchen
pip install -r requirements.txt
```

### 3. 准备模型文件

以下文件**不随 Git 分发**（太大），需手动放置到 `backend/models/`：

| 文件 | 来源 | 说明 |
|------|------|------|
| `clip_vit_b32.pth` | 运行 `python download_models.py` 或手动下载 | CLIP ViT-B/32 权重（605MB） |
| `clip_classifier.pth` | 运行 `train_clip.py` 训练 | 15 类分类头（92.69%） |
| `student_mobilenetv3.pth` | 运行 `train_distill.py` 训练 | 轻量端侧模型（90.83%，6MB）|

> 模型加载优先级：CLIP → MobileNetV3 蒸馏 → 无模型时 API 返回 503 提示。

### 4. 配置 AI 营养师（可选但推荐）

```bash
# Windows
set DEEPSEEK_API_KEY=sk-你的密钥

# Linux/Mac
export DEEPSEEK_API_KEY=sk-你的密钥
```

获取地址：https://platform.deepseek.com （国内直连，无需 VPN）

### 5. 启动服务

```bash
python -m backend.app
```

验证：浏览器访问 http://localhost:8686 ，看到 `{"service": "SmartKitchen"}` 即成功。

### 6. 可用 API

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/recognize` | 单食材识别（上传图片） |
| POST | `/api/recognize/meal` | 整餐多食材分析（3x3 网格） |
| GET | `/api/nutrition?name=苹果&weight=100` | 营养查询 |
| GET | `/api/recipes?type=晚餐` | 菜谱推荐 |
| GET | `/api/history` | 饮食记录 |
| GET | `/api/health-score?member=default` | 健康评分 |
| GET | `/api/leaderboard` | 家庭排行榜 |
| POST | `/api/chat` | AI 营养师对话 |
| GET/POST | `/api/face-auth/*` | 人脸注册/验证 |

## 三、前端部署（HarmonyOS）

### 1. 环境

- DevEco Studio（HarmonyOS NEXT，API 11）

### 2. 配置后端地址

打开 `A11451411/entry/src/main/ets/utils/DataModels.ets`：

```typescript
// 改成你电脑的局域网 IP（ipconfig 查看），手机和电脑连同一 WiFi
static backendUrl: string = 'http://192.168.x.x:8686'
```

### 3. 编译部署

DevEco Studio 打开 `A11451411/` → Sync → Build → 部署到手机/开发板。

### 4. 页面结构（5 Tab）

```
首页   — 拍照识别（单食材/整餐模式切换）
营养   — 健康评分 + 今日热量 + 历史入口
菜谱   — 菜谱广场 + 膳食指南
助手   — AI 营养师对话（DeepSeek）
我的   — 记录/指南/成员/人脸 设置列表
```

详见 [`docs/开发板-通晓TX-SMART-R.md`](docs/开发板-通晓TX-SMART-R.md)

- 通晓 TX-SMART-R（RK2206 + OpenHarmony Lite）
- 烧录：DriverInstall.exe → RKDevTool.exe → mask+reset
- 日志：MobaXterm 串口 115200
- 集成方向：红外触发拍照、光强自适应、温湿度监测、HX711 食材称重、MQTT 上报

### 采购清单（约 60-100 元）

|------|------|--------|
| E53 摄像头扩展板 | 开发板拍照 + 端侧粗分类 | 30-80 元 |

## 六、常见问题

**Q: 后端提示"模型未加载"？**
A: `backend/models/` 下缺少模型权重，运行训练脚本或下载权重。

**Q: 前端连不上后端？**
A: 检查：① 手机和电脑同一 WiFi；② `backendUrl` 是电脑局域网 IP 不是 localhost；③ 后端已启动；④ 防火墙放行 8686 端口。

**Q: AI 营养师说"未配置"？**
A: 设置环境变量 `DEEPSEEK_API_KEY` 后**重启后端**。

**Q: 人脸识别接口 503？**
A: 需安装 `pip install mediapipe deepface`（CountBot 人脸模块依赖）。
