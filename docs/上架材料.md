## 三、详细简介（应用详情页）

食光记是一款基于 AI 的智能厨房助手应用，帮你轻松管理一日三餐：

- **拍照识食材**：对准食材拍一张，秒级识别 15 类常见食材（水果、蔬菜、肉蛋、主食），离线模型本地运行，无网络也能用
- **整餐营养分析**：拍一桌菜，自动识别多种食材并汇总整餐热量、蛋白质、脂肪、碳水
- **健康评分**：参照《中国居民膳食营养素参考摄入量（2023）》，从热量、蛋白、脂肪、碳水、多样性五个维度给你的饮食打分
- **AI 营养师**：接入大模型的智能问答，结合你的饮食记录给出针对性建议
- **菜谱推荐**：按早/午/晚餐分类推荐，营养搭配不重样
- **饮食记录**：历史记录与统计一目了然，坚持打卡看得见
- **家庭成员管理**：人脸识别登录，每个人独立记录与排行
- **智能开发板联动**（可选）：搭配智能厨房开发板，实时查看温湿度、食材称重、变质预警
- **双风格界面**：液态玻璃 / 简约两种视觉风格自由切换，深浅色模式自动适配

## 六、Release 打包步骤（DevEco Studio）

1. **登录 AGC**（[developer.huawei.com](https://developer.huawei.com) → AppGallery Connect → 我的项目）创建项目和应用，**包名填 `com.hulei.shiguangji`**
2. **生成证书**：AGC 控制台 → 证书/APP ID → 创建发布证书（.p12）+ Profile（.cer）
3. **DevEco 配置签名**：File → Project Structure → Signing Configs → 勾选 Automatically generate signature（或手动导入发布证书 + Profile）
4. **打包**：Build → Build Hap(s)/APP(s) → Build APP(s) → 选择 Release，产物为 `.app` 文件（在 `entry/build/default/outputs/`）
5. **上传**：AGC 控制台 → 应用 → 版本管理 → 创建版本 → 上传 .app → 填写版本说明
6. **填写审核信息**：简介、截图、隐私政策 URL（必填）、权限说明（相机/存储/网络——权限用途要和隐私政策一致）
7. **提交审核**

## 七、审核常见打回原因（提前避坑）

1. **隐私政策缺失/地址不可访问** —— 最常见的打回原因，务必先部署一个可访问的 URL
2. 截图与功能不符、截图模糊
3. 权限申请理由与实际不符（相机权限要有明确使用场景说明）
4. 应用内出现"测试""demo"字样
5. AI 功能未说明数据流向（隐私政策第 4 条已覆盖，若审核问询可补充说明）
