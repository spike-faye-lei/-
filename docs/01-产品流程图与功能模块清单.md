## 人工干预率

| 流程节点 | 处理方式 | 人工？ |
|---|---|---|
| 简历获取/解析 | 平台接口 + 自动解析 | 否 |
| 规则硬筛/匹配/加分打分 | 算法自动 | 否 |
| 初筛结果复核 | **人工勾选（仅确认）** | ✅ 节点① |
| 面试通知/面试执行/评分 | 全自动 | 否 |
| 最终录用决策 | **HR 审批（唯一必须人工）** | ✅ 节点② |
| 通知/Offer 发送 | 自动触发（渠道可配） | 否 |
| 培训匹配/入职归档 | 自动 | 否 |

**干预率 ≈ 2/12 ≈ 17%（当前）**；目标 <10%：初筛复核改为"仅抽查+超时自动通过"后可达 1/12 ≈ 8%。

## 功能模块清单

| 模块 | 状态 | 说明 |
|---|---|---|
| 岗位管理（JD + 筛选规则配置） | ✅ 已上线 | HR 人工输入硬性条件，写入数据库 |
| 简历库（批量导入 + 全文检索 + 授权日志） | ✅ 已上线 | 文件落盘 + 解析入库，生产换 ES 检索 |
| 智能初筛（规则60/匹配30/加分10） | ✅ 已上线 | 淘汰原因可解释，状态落库 |
| AI 面试（自适应追问 + 证据链评分） | ✅ 已上线 | 流式直播 + 维度覆盖检查 |
| 待审核队列 + HR 闸门 | ✅ 已上线 | 从库加载逐条审核，唯一人工决策点 |
| 通知/Offer 自动生成与发送 | ✅ 已上线 | 渠道抽象（企业微信/短信/邮件），本地模拟发送 |
| 入职运营（培训匹配 + 归档） | ✅ 已上线 | 内置课程库关键词匹配 |
| 全流程看板（漏斗 + 算法说明） | ✅ 已上线 | 状态机统计 |
| 数字人/语音面试 | 📋 规划 | 先语音问答+固定题库，再数字人（方案见 04） |
| 防作弊（摄像头/切屏检测） | 📋 规划 | 面试页前端监测，与线上会议对接一起做 |
| 招聘平台对接 | 📋 规划 | 方案见 02（官方 API 优先，RPA 备选） |
