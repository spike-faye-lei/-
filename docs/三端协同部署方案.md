## 识别链路（级联）

| 层 | 模型 | 准确率 | 大小 | 位置 |
|----|------|--------|------|------|
| 1. 粗分类 | TinyCNN（4 类） | 75.9% | **6KB** | 开发板 |
| 2. 端侧细分类 | MobileNetV3-Small（蒸馏） | 90.83% | 6MB | 手机 App |
| 3. 云端高精度 | CLIP ViT-B/32（冻结） | 92.69% | 605MB | 后端 |

**流程**：开发板粗分类 → 手机 App 离线细分类（无网络秒出）→ 复杂场景/整餐 → 后端 CLIP 兜底。

## 数据传输路径（开发板 → 手机）

```
开发板 --MQTT(topic: kitchen/board1/sensor)--> 后端 paho 订阅
  后端 --SQLite 存库 + WebSocket 广播--> 手机 App 实时显示
  手机 --REST GET /api/board/status--> 轮询兜底（10s）
```

### 后端配置

```bash
# 启动时设置环境变量即自动连接 MQTT
export MQTT_HOST=192.168.1.100   # MQTT Broker 地址（可用 EMQX/Mosquitto）
export MQTT_PORT=1883
python -m backend.app
```

### 手机端

- `我的 → 开发板状态` 页面，每 10 秒轮询 REST + 可扩展 WebSocket 实时推送
- 后端未启动 MQTT 时，页面显示"开发板离线"，不影响其他功能

## 文件清单

| 文件 | 说明 |
|------|------|
| `board/board_main.c` | 开发板主程序（传感器+MQTT+TinyCNN 推理） |

| `backend/database.py` | board_events 表 |

| `export_onnx.py` | 蒸馏模型 ONNX 导出 |
| `entry/.../BoardPage.ets` | 手机端开发板状态页 |

## 开发板固件烧录步骤

1. 训练/获取权重：`python train_tinycnn.py` → 生成 `tinycnn_weights.h`
2. 把头文件放入 OpenHarmony 源码 `vendor/isoftstone/rk2206/samples/smartkitchen/`
3. 编译：参照 docs/开发板-通晓TX-SMART-R.md 的 Hello World 流程
4. 烧录：DriverInstall.exe → RKDevTool.exe → mask+reset
5. 配置 board_main.c 中的 WiFi 与 MQTT Broker 地址

## 手机端 ONNX 集成（MindSpore Lite）

1. `export_onnx.py` 已生成 `student_mobilenetv3.onnx`（6.1MB，已验证输出一致）
2. 使用 MindSpore Lite 转换工具转 .ms 格式
3. NAPI 封装推理调用，ArkTS 侧调 `predict(imagePath)` 返回 15 类结果
4. 断网场景：App 直接使用本地模型识别（90.83%），联网时可选后端 CLIP（92.69%）
